# Firebase Mini Project

A Flutter app that uses **Firebase Authentication** to sign users in and **Cloud Firestore** to save and display user data.

## Features

- **Login** with email and password (Firebase Authentication)
- **Sign Up** with form validation (full name, email, password, confirm password)
- **User Form** that saves Name, Age and Favourite Hobby to Cloud Firestore
- **Display Users** page that shows all saved records, updated live from Firestore
- English and Arabic support (`easy_localization`) with a language switch button
- Show / hide password button
- Fade page transition after a successful sign up

## App Flow

`Login` -> (success) -> `User Form` -> `Display Users`

New users open `Sign Up` from the Login page, and after creating the account they are taken to the `User Form`.

## Tech Stack

- Flutter & Dart
- Firebase CLI / FlutterFire CLI
- `firebase_core`, `firebase_auth`, `cloud_firestore`
- `easy_localization`

| Field   | Type   |
| ------- | ------ |

| `age`   | String |
| `hobby` | String |

## Getting Started

### Prerequisites

- Flutter SDK installed (`flutter doctor` shows no errors)
- A Firebase account

### Run the project

1. Clone the repository:
   ```bash
   git clone https://github.com/RadwaAlzayat/firebase_project.git
   cd firebase_project
   ```
2. Install the packages:
   ```bash
   flutter pub get
   ```
3. Connect your own Firebase project:
   ```bash
   npm install -g firebase-tools
   firebase login
   dart pub global activate flutterfire_cli
   flutterfire configure
   ```
   This regenerates `lib/firebase_options.dart` for your project.
4. In the [Firebase Console](https://console.firebase.google.com):
   - **Authentication** -> Sign-in method -> enable **Email/Password**
   - **Firestore Database** -> Create database (test mode is fine while learning)
5. Run the app:
   ```bash
   flutter run
   ```
